# Kasir Kedai Iboen

Versi 1.0 — aplikasi kasir offline, login Owner, menu editable + emoji, transaksi, laporan, pengaturan.

## Login awal
- Username: owner
- Password: 1234

## Fitur
- Splash/banner Kedai Iboen saat aplikasi dibuka
- Dashboard Owner
- Tambah/edit/hapus menu
- Pilih emoji menu
- Transaksi dan kembalian
- Laporan penjualan harian
- Pengaturan nama kedai/alamat/WhatsApp
- Ganti password Owner
- Data menu dan pengaturan tersimpan lokal/offline

## Cara build di Android Studio / AndroidIDE
1. Extract ZIP.
2. Buka folder `Kasir_Kedai_Iboen` sebagai project Gradle.
3. Tunggu Gradle sync selesai.
4. Pilih `app` > build APK / Generate APK.
5. Install APK hasil build.

Catatan: project ini sengaja tidak memakai library pihak ketiga sehingga lebih ringan dan mengurangi error dependency.
